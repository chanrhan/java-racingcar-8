# 2주차 과제 : 자동차 경주
## 기능 요구사항
### 1) 입력
- `,`를 구분자로 하여 자동차 이름들을 문자열로 입력받는다
- 시도할 차수를 입력받는다.

### 2) 자동차 움직임
- 각 차수마다, 각 자동차는 0~9 사이의 무작위 값을 구하여, 4 이상일 경우에만 전진한다.
- 모든 차수가 끝날 때, 가장 멀리 이동한 자동차가 우승자가 되며, 우승자는 여러 명일 수 있다.

### 3) 출력
- 차수별 실행 결과를 출력해야 한다.
- 모든 차수가 종료되면, 우승자 이름을 출력한다. 
- 우승자가 여러 명일 경우, `,`를 구분자로 하여 모두 출력한다. 

### 4) 예외
- 사용자가 잘못된 값을 입력했을 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션을 종료해야 한다.
